# 🎮 GameTunes - Gaming Music Player

A modern web-based music player for gaming soundtracks built entirely using **HTML, CSS, and JavaScript** in a single HTML file.

## ✨ Features

- 🎵 Music Player
- ▶️ Play / Pause Songs
- ⏮ Previous / Next Controls
- 🔍 Search Songs
- 📈 Progress Bar
- 🔊 Volume Control
- 📱 Responsive Design
- 🎨 Modern Glassmorphism UI
- ⚡ Smooth Animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/yourusername/GameTunes-Music-Player.git
```

2. Open **index.html** in your browser.

That's it! No installation or dependencies required.
